Como funciona esta tela
  • Cada pessoa aparece uma vez só, pelo CPF, com os papéis que tem: funcionário, voluntário e doador associado. Funcionário e voluntário não podem ser a mesma pessoa ao mesmo tempo.
  • Cadastrar aqui não passa por triagem: é você quem está registrando. Voluntário cadastrado aqui preenche o termo de adesão; o menor de idade fica pendente até a autorização do responsável chegar na sede.
  • Doador associado não é cadastrado aqui: a conta nasce com a primeira doação associativa feita no site.
  • Não existe excluir. Para tirar alguém, inative o papel — os dados ficam guardados e dá para reativar. Apagar dados pessoais só por pedido do titular, na tela Privacidade (LGPD).
